# リスクスコアリング方針

このドキュメントは、Plamo Design Feedback AI のリスクスコアがどのような考え方で計算されるかを説明するものです。

本プロジェクトは学習・ポートフォリオ用のプロトタイプであり、実在商品、公式データ、実際の金型データ、不具合報告は使用していません。スコアは架空データに対するルールベース推定です。

## 基本方針

リスクスコアは、ユーザーフィードバックから検出した問題カテゴリと、CSVに含まれる架空の部品特徴を合算して0から100で表します。

単なるポジティブ/ネガティブ判定ではなく、以下を結びつけることを重視しています。

- ユーザーの声: 固い、折れそう、ゆるい、分かりにくいなど
- 設計特徴: 部品サイズ、材料、可動部、ゲート位置、想定荷重など
- 開発改善観点: 設計、金型、説明書、ユーザー体験

## 主なカテゴリ加点

| 問題カテゴリ | 加点 |
| --- | ---: |
| `breakage_risk` | +35 |
| `tight_joint` | +25 |
| `loose_joint` | +20 |
| `small_parts` | +20 |
| `assembly_difficulty` | +15 |
| `instruction_unclear` | +10 |
| `gate_mark` | +10 |
| `satisfaction_positive` | -10 |

## 重要度加点

| severity | 加点 |
| --- | ---: |
| `high` | +20 |
| `medium` | +10 |
| `low` | +0 |

## 部品特徴による加点

| 条件 | 加点 |
| --- | ---: |
| `part_size=small` かつ `breakage_risk` | +15 |
| `moving_part=true` かつ `tight_joint` | +15 |
| `moving_part=true` かつ `loose_joint` | +10 |
| `estimated_load=high` | +10 |
| `gate_position=front` かつ `gate_mark` | +10 |
| `material_type=ABS` かつ `tight_joint` | +5 |

## 企業開発で使う場合の注意

実務で使う場合は、現在の重みをそのまま使うのではなく、以下のデータで校正する必要があります。

- 試作サンプルの破損率、白化発生率、保持力測定値
- 組み立てレビューの母数、ユーザーレベル、誤組み件数
- CAD寸法、公差、材料、ランナー配置、ゲート設計情報
- 品質保証部門の不具合分類と再現確認結果

このMVPでは、説明可能なルールを先に作り、あとからLLMや統計モデルに置き換えやすい構成にしています。
