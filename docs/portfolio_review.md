# Portfolio Review

## 総合評価

このプロジェクトは、就活ポートフォリオとしては「動くMVP」から一段進み、設計判断、可視化、テスト、権利配慮まで説明できる状態です。企業の技術者視点では、Junior上位からMid相当の実装力を示せます。

特に評価されやすい点は、ユーザーフィードバックを単に感情分類するのではなく、部品サイズ、材料、可動部、ゲート位置、想定荷重といった設計特徴に結びつけ、改善優先度として可視化している点です。

ただし、本制作物は開発中です。現在のランナー画像・完成後画像は説明用の仮素材であり、適切な検証素材としては扱いません。今後、権利処理済み素材を用意する予定ですが、準備が難しい場合に備えて模式図・検査点マップ・部品特徴データ表で説明する別案も検討しています。

## 技術的に伝わる強み

- `feedback_analyzer.py`、`risk_scorer.py`、`improvement_generator.py`、`part_visualizer.py`、`llm_adapter.py` の責務が分かれており、分類、採点、改善案、可視化、LLM補助を個別に説明できます。
- `risk_score` はルールベースで固定し、ローカルLLMは原因説明や改善仮説の補強だけに使うため、AI出力に依存しすぎない設計になっています。
- ランナー画像や試作写真を入力し、画像から読み取った部品特徴を指定すると、切り出し前のゲートリスクや破損リスクの評価が返る導線を持っています。
- 架空データと自作生成画像のみを使い、公式画像、実在商品レビュー、実際の金型データを使わない方針を明記しています。
- CIでコンパイル、単体テスト、Streamlitスモークテスト、画像生成を確認する構成になっています。

## AI活用の意図

このアプリのAI活用は、玩具そのものへAI機能を入れる方向ではなく、商品開発と品質改善を支援する方向です。

開発現場で実際に価値が出るのは、レビュー文をそのまま読むだけでなく、どの部位に、どの工程で、どの設計特徴と結びついた不満が集まっているかを早く見つけることです。このプロトタイプでは、ルールベース分析で説明可能性を確保しつつ、ローカルLLMで設計者向けの補足説明を生成できる余地を作っています。

## UI・可視化の評価

ダッシュボードでは、総件数、高リスク件数、最優先改善部位、主要カテゴリ、平均スコアを最初に提示しており、採用担当にも目的が伝わりやすい構成です。

ランナー検査ビューは、架空ランナー画像にゲート点、部品番号、リスクマーカーを重ねることで、切り出し前に見るべき箇所を説明しやすくなっています。さらに、ランナー画像・特徴データ入力評価により、写真や模式図を見ながら部品サイズ、ゲート位置、切り出し時の負荷を指定し、評価結果と改善案を返せる構成になっています。

## 残っている課題

- サンプルデータは架空のため、リスク重みの妥当性は実測データで検証できていません。
- 現在の画像ベース分析は、実画像認識ではなく、アプリが描画した検査点を構造化して読み解く実装です。
- 現在のランナー画像・完成後画像は最終的な検証素材に適しておらず、差し替え方法も未決定です。
- ローカルLLMは既定で無効な任意機能であり、自分のPCで明示的に有効化し、Ollamaとモデルを用意した場合だけ補強分析を実行できます。
- テストは主要ロジックを押さえていますが、UI操作の詳細、CSV異常系、LLM応答の揺れに対する網羅性は拡張余地があります。

## 面接での説明ポイント

1. ユーザーの声を分類するだけでなく、部品特徴と結びつけて改善優先度を出す設計にした。
2. ランナー画像/部品特徴を入力にして、ゲート位置、細い部品、小型部品、切り出し負荷を評価対象にした。
3. スコアリングは説明可能なルールベースにし、LLMは再採点させず、原因説明と改善仮説の補強に限定した。
4. 実在商品や公式画像を使わず、権利・機密に配慮した架空データだけでデモを成立させた。
5. 将来的には、試作レビュー、CAD特徴量、権利処理済み画像、不具合報告と連携して、開発改善支援ツールへ拡張できる。

## 次に伸ばすなら

- 実測データを想定したスコア重みの校正手順を追加する。
- 第一案として、権利処理済みのランナー写真、試作サンプル写真、ラベル付き検査データを用意する。
- 素材準備が難しい場合は、模式図、検査点マップ、部品特徴データ表を中心にした説明へ切り替える。
- Local LLMの出力をレポートに取り込み、ルールベース結果との差分を保存できるようにする。
- Streamlit画面を提出用の短いデモ導線に整理し、最初の1画面でプロジェクト価値が伝わるようにする。
