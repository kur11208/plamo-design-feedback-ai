# 画像素材の更新計画

## 現在の判断

Plamo Design Feedback AIは開発中のプロトタイプです。現在のランナー画像・完成後画像は機能説明用の仮素材であり、適切な実画像認識データや実用性の根拠としては扱いません。

公開デモの評価対象は、架空データと説明可能なルールベース処理です。画像入力機能は、ROI指定、画像適性警告、軽量な特徴候補の提案までを確認するための試作です。

## 第一案: 権利処理済み素材を用意する

今後、次の条件を満たすランナー写真・試作サンプル写真を用意する予定です。

- 撮影者、権利者、公開可能な範囲を記録できる
- 単体ランナーを正面から撮影し、箱、説明書、シール、ロゴ、強い反射が重ならない
- 部品ID、ゲート位置、細い部位、小型部品などの注釈基準を説明できる
- README、公開デモ、スクリーンショットの用途ごとに利用可否を確認できる
- 同じ条件で複数枚を用意し、1枚だけの見栄えを検証結果として扱わない

## 別案: 実物写真に依存しない

素材を継続的に用意することが難しい可能性もあるため、次の構成も検討しています。

- 架空ランナーの模式図
- 部品とゲート位置を示すワイヤーフレーム
- リスク箇所と確認順を示す検査点マップ
- 部品ID、寸法、材料、ゲート位置を持つ構造化データ表
- 入力、特徴候補、人による修正、リスク評価の流れを示す画面

この案では、写真らしさではなく、入力条件、判断根拠、修正可能性を説明できることを優先します。

## 方針を決める基準

次の条件を満たせる場合は第一案を採用します。

- 公開可能な素材を複数枚用意できる
- 出所と利用範囲をREADMEに記載できる
- 注釈と評価手順を再現できる

いずれかを満たせない場合は、別案を採用します。現時点では最終方針を決定していません。

## 差し替え完了の条件

- 現在の仮画像を最終成果の画像として扱わない
- 採用した素材または模式図の出所と用途を明記する
- README、公開デモ、ポートフォリオ記事の説明を一致させる
- 入力画像に対するROI、警告、人による確認手順を検証する
- 更新後のスクリーンショットとテスト結果を再生成する
